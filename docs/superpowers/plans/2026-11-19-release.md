# Commerce Lens implementation plan

The November 19 release joined a React workbench, FastAPI service and DuckDB warehouse in a clonable repository. The following work packages record the implementation plan and its acceptance checks. Historical results and remaining experiments are in the verification record. [Verification record](../../verification.md)

- [x] **Data and statistics.** Implement import and review comparison in `commerce/data.py` and `commerce/stats.py`. Check a multi-payment order and two known groups of ratings for amounts, sample selection and test choice.
- [x] **Query workflow.** Implement the compatible HTTP adapter, offline question catalog and bounded SQL execution. Feed controlled responses through the controller for success, rejection, empty results and recovery.
- [x] **Workbench.** Build overview, questions, investigation, metrics, evaluation and history under `frontend/`. Run `npm ci` and `npm run build`. Check charts, evidence and mobile layout in a browser.
- [x] **Integration.** Serve the application through `commerce/api.py`, manage data and evaluation through `commerce/cli.py`, and persist runs in SQLite. Test the path from API request to data and evidence.
- [x] **Evaluation tooling.** Store 55 cases and independent reference queries under `evaluation/`. Record snapshot, mode, outcome and timing. Real-model experiments require configured access and human review of the reference set.
- [x] **Release.** Provide native startup, Docker Compose, CI, README and acceptance record. Exercise clean checkout and startup. Verify anonymous clone and remote CI for the published commit.
