# Commerce Lens 实施计划

目标是在一份可克隆的源码中交付 React 工作台、FastAPI 服务和 DuckDB 分析。按独立模块并行实现，再通过 API、浏览器和干净克隆验收。

- [x] 数据与统计。commerce/data.py、commerce/stats.py 负责导入和比较。用多支付订单及两组评分复核金额、样本选择与检验。
- [x] 查询。commerce/agent.py 接入兼容 HTTP 服务、离线问题目录、受限 SQL 执行。用可控模型响应检查成功、拒绝、空结果和错误恢复。
- [x] 工作台。frontend/ 实现概览、工作台、调查、指标、评估、历史。运行 npm ci 和 npm run build，浏览器核对图表、证据和移动布局。
- [x] 集成。commerce/api.py 提供同源服务，commerce/cli.py 管理数据与评估，运行 SQLite 保存请求。用 pytest 检查 API → 数据 → 证据完整链路。
- [x] 实验。evaluation/ 存放独立参考查询与 55 题，比较实际结果，记录数据版本、模式和耗时。真实模型实验由配置触发。
- [x] 发布。提供本地脚本、Docker Compose、CI、README 和验收报告。在全新检出上启动；推送后核对匿名克隆和远程 CI。
